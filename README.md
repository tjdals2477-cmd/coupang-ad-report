# 쿠팡 광고 보고서 생성기

쿠팡 Wing 광고 보고서 엑셀(직전월·금월)을 올리면 계정별 HTML 보고서를 만들고, 여러 계정 보고서를 하나로 통합합니다.
생성된 HTML은 다운로드 후에도 `✏️ 편집` 버튼으로 수정·저장할 수 있습니다.

## 추이 차트 (핵심 지표 아래)
- 쿠팡 Wing 광고 보고서를 **'일별'로 내려받으면** (`날짜` 컬럼 포함) 추이 차트가 기간 길이에 맞춰 그려집니다.
  - 월 단위 파일 → **7일 단위** 굴곡 (7일 미만인 월말 구간은 속 빈 점으로 표시)
  - 7일·14일 파일 → **1일 단위** 굴곡
  - 두 파일은 같은 단위로 비교합니다 (한쪽이라도 14일을 넘으면 둘 다 7일 단위).
- 날짜가 없는 합계 파일이면 직전월·금월 2점 차트로 그립니다.
- 총매출은 엑셀에 없어 앱에서 입력합니다 (일별 파일이면 구간별 입력표). **한 칸이라도 비면 차트는 생성되지 않습니다.**

## 온라인 배포 (Streamlit Community Cloud · 무료)

공개 앱 + **접속 비밀번호** 방식으로 운영합니다. 저장소에는 코드만 있고(광고 데이터 없음),
업로드한 엑셀은 서버 메모리에서만 잠시 처리됩니다.

### 접속 비밀번호 설정 / 변경
1. <https://share.streamlit.io> → 앱 오른쪽 `⋮` → **Settings** → **Secrets**
2. 아래 한 줄을 입력하고 저장 (따옴표 포함)
   ```
   APP_PASSWORD = "원하는 비밀번호"
   ```
3. 비밀번호가 설정되지 않으면 앱은 열리지 않습니다. 로컬 `실행.bat`은 비밀번호 없이 열립니다.

### 수정 반영
코드를 고친 뒤 `git push` 하면 앱이 자동으로 다시 배포됩니다.

### 새로 배포할 때
share.streamlit.io › **Create app** › 저장소 `coupang-ad-report` · Branch `main` · Main file path `app.py`

## 참고
- 한동안 접속이 없으면 앱이 잠들며, 다음 접속 시 깨우는 데 수십 초가 걸립니다.
- 업로드한 엑셀은 앱 서버 메모리에서만 처리되고 저장소에는 남지 않습니다. 엑셀·보고서·설정 JSON은 `.gitignore`로 커밋에서 제외됩니다.
- 로컬에서 실행하려면 `실행.bat`을 더블클릭하세요.
- 테스트: `py -m unittest discover -s tests`
