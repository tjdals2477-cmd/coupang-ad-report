# 쿠팡 보고서 생성기

왼쪽 메뉴에서 두 가지 보고서를 만듭니다. 생성된 HTML은 다운로드 후에도 `✏️ 편집` 버튼으로 수정·저장할 수 있고,
계정별 보고서를 상단 탭형 한 파일로 통합할 수 있습니다.

| 페이지 | 넣는 파일 | 결과 |
|---|---|---|
| 📊 광고 보고서 | 쿠팡 광고 보고서 엑셀(직전월·금월) | 캠페인·상품 단위 광고 운영 보고서 |
| 📈 월간 성과 보고서 | Wing 비즈니스 인사이트(월별) + 광고 raw(선택) + 주차 대시보드(선택) | 타부서 공유용 월별 매출·광고비·자연매출·방문자·구매전환율 + 매출 급변 상품 |

## 📈 월간 성과 보고서
**넣는 파일**
1. **비즈니스 인사이트** (필수, 월별 파일 여러 개) — Wing › 비즈니스 인사이트에서 월별로 내려받은 엑셀.
   `기간별 판매량`(일별)·`상품별 판매량`(옵션별) 시트를 이름으로 찾습니다. 상품별만 따로 받은 파일도 함께 올리면
   일별 매출 합계와 맞는 쪽을 자동 선택하고, 맞지 않으면 경고합니다.
2. **광고 raw** (선택) — 광고센터 일자별·옵션별 보고서, 광고보고서 xlsm(`raw` 시트), 상품 전환 보고서. 급변 상품의 광고 상태·광고비와
   광고 합계 빈 날 보정에 씁니다. 헤더 표기 차이(`광고 집행 옵션 ID`·`광고비(원)` 등)는 자동으로 맞춥니다.
   - **날짜 없이 기간 전체로 내려받은 파일**(예: `안트_9월 광고 보고서.xlsm`)은 기간 합계로 처리합니다. 기간은 파일명
     (`9월`, `0901-0909`, `9월16~9월22일`)에서 읽고 화면에서 고칠 수 있습니다.
   - 캠페인이 2개 이상이면 '계정 전체 광고'로 보고 월 광고 합계에 **대시보드보다 우선** 사용합니다(쿠팡 원본 수치). 캠페인 1개짜리
     파일은 옵션별 광고비에만 반영합니다. 그 기간 안에서는 일별 raw보다 기간 합계를 우선합니다.
3. **주차 대시보드** (선택) — `시작일·종료일·광고비용·광고매출` 열이 있는 시트(시트명 = 계정명이면 자동 선택).

**계산 규칙**
- 광고 합계 우선순위: 광고보고서 기간 합계(계정 전체) > 대시보드 > 화면에서 입력한 보정값 > 광고 raw 일합계. 기간의 90% 이상이 채워져야 광고 지표를 표시합니다.
- 진행 중인 달은 직전 달 같은 일수(예: 9/1~18)와 비교, 광고비는 일평균 비교. 집계 마지막 날은 방문자가 있는 마지막 날(당일 부분집계 제외).
- 자연매출 = 총매출 − 광고전환매출(14일) · 구매전환율 = 주문 ÷ 조회 (Wing·서플라이어 허브 화면 정의, 월 총계와 일치. 조회 칸이 없으면 방문자 가중평균).
- 상품별 시트 이름에 `TOP`이 있으면(예: `상품별 판매량(TOP10)`) 상위 상품만 담긴 것으로 보고 합계 대조를 건너뛰고, 진행 중인 달은 일수로만 환산합니다. 로켓배송(서플라이어 허브) 계정은 판매 분석 화면 수집본을 이 형식으로 변환해 올립니다.
- 급변 상품: |증감액| ≥ 50만원 AND |증감률| ≥ 15% (화면에서 변경). 진행 중인 달은 일평균×월 일수로 환산.
- 채널 이동: 옵션명이 같고 판매방식(판매자배송·로켓그로스)만 다른 옵션이 반대로 움직이면 자동 표시(같은 기간=동시, 첫 달→마지막 달=시차).
  옵션명이 달라 못 묶는 경우 화면의 '채널 매칭 수동 추가'에 옵션ID 쌍을 입력합니다.
- 광고 상태: 광고 raw 마지막 7일 광고비 > 0 → 집행중 / 그 전에 끊김 → 중단 / 마지막 집행일 다음 날부터 데이터가 없으면 확인필요.

**보고서에서 클릭하면 펼쳐지는 상세** (편집 모드에서는 동작하지 않음)
- **총매출 카드** → 카테고리별 월 매출·비중·증감. '품목군'(상품명 키워드, `monthly/analysis.py`의 `ITEM_GROUPS`에서 수정)과
  '쿠팡 카테고리' 두 가지 보기. 진행 중인 달은 월환산, 상품별 데이터가 TOP 10뿐이면 그 범위 안의 흐름.
- **광고비 카드** → 월별 캠페인 KPI(광고비·광고매출·ROAS·노출·클릭·CTR·CPC·주문·전환율, 14일 기준). 캠페인 행을 누르면
  광고한 품목 TOP 10. 기간 합계 광고보고서가 그 달을 덮으면 우선, 아니면 일별 raw(데이터 일수를 함께 표시).
- **급변 상품 행** → 그 품목의 월별 매출·판매수량·주문·방문자·개당 매출·광고비(진행 중인 달은 환산 없이 실제값).

## 📊 광고 보고서
쿠팡 Wing 광고 보고서 엑셀(직전월·금월)을 올리면 계정별 HTML 보고서를 만들고, 여러 계정 보고서를 하나로 통합합니다.

## 추이 차트 (핵심 지표 아래)
- 쿠팡 Wing 광고 보고서를 **'일별'로 내려받으면** (`날짜` 컬럼 포함) 추이 차트가 기간 길이에 맞춰 그려집니다.
  - 월 단위 파일 → **7일 단위** 굴곡 (7일 미만인 월말 구간은 속 빈 점으로 표시)
  - 7일·14일 파일 → **1일 단위** 굴곡
  - 두 파일은 같은 단위로 비교합니다 (한쪽이라도 14일을 넘으면 둘 다 7일 단위).
- 날짜가 없는 합계 파일이면 직전월·금월 2점 차트로 그립니다.
- 총매출은 엑셀에 없어 앱에서 입력합니다 (일별 파일이면 구간별 입력표). **한 칸이라도 비면 차트는 생성되지 않습니다.**

## 온라인 배포 (Streamlit Community Cloud · 무료)

공개 앱 + **접속 비밀번호** 방식으로 운영합니다. 저장소에는 코드만 있고(광고 데이터 없음),
업로드한 엑셀은 서버 메모리에서만 잠시 처리됩니다.

### 접속 비밀번호 설정 / 변경
1. <https://share.streamlit.io> → 앱 오른쪽 `⋮` → **Settings** → **Secrets**
2. 아래 한 줄을 입력하고 저장 (따옴표 포함)
   ```
   APP_PASSWORD = "원하는 비밀번호"
   ```
3. 비밀번호가 설정되지 않으면 앱은 열리지 않습니다. 로컬 `실행.bat`은 비밀번호 없이 열립니다.

### 수정 반영
코드를 고친 뒤 `git push` 하면 앱이 자동으로 다시 배포됩니다.

### 새로 배포할 때
share.streamlit.io › **Create app** › 저장소 `coupang-ad-report` · Branch `main` · Main file path `app.py` (페이지는 `views/`)

## 참고
- 한동안 접속이 없으면 앱이 잠들며, 다음 접속 시 깨우는 데 수십 초가 걸립니다.
- 업로드한 엑셀은 앱 서버 메모리에서만 처리되고 저장소에는 남지 않습니다. 엑셀·보고서·설정 JSON은 `.gitignore`로 커밋에서 제외됩니다.
- 로컬에서 실행하려면 `실행.bat`을 더블클릭하세요.
- 테스트: `py -m unittest discover -s tests`
